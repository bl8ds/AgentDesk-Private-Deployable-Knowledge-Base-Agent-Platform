## 1. 交付边界（Phase 1）

### 1.1 平台方交付

| 交付物 | 说明 |
|--------|------|
| C 端 H5 对话应用 | React + assistant-ui，可嵌入使用方 App WebView |
| 运营管理后台 | 自研；语料同步入口、配额、审计查看 |
| 业务 BFF | Go 服务：鉴权、额度、对话代理、审计 |
| 知识引擎 | RAGFlow **私有化部署**（内网组件，不对 C 端暴露其原生 UI） |
| 文档 | 部署手册、环境变量、联调说明、验收记录 |
| 源码 | 约定范围内的 H5 / 后台 / BFF 源码；引擎以官方发行版 + 配置交付 |

### 1.2 Phase 1 包含

- 文档导入（以 RAGFlow 支持格式为准；文本型 PDF/Office/MD 等）  
- 知识库问答（流式）+ 引用溯源  
- 无依据拒答（提示词 + 引用校验）  
- App 免登（一次性授权码）  
- 用户级问答额度  
- 基础审计与内容安全钩子（厂商 Key 使用方提供）  
- WebView 联调通过  

### 1.3 Phase 1 不包含

- NewAPI / OneAPI 或任何「模型中转站 UI」  
- AI 生图 / 生视频  
- 复杂商品推荐 / ERP 深度对接  
- 等保 / 信创一次性打包  
- 把 RAGFlow / Dify 原生控制台作为使用方 C 端或对外品牌后台  
- 原生 iOS/Android 对话 SDK（仅 H5）  

### 1.4 责任划分

| 事项 | 使用方 | 平台方 |
|------|------|--------|
| 服务器、域名、证书 | 提供 | 部署协助 |
| 大模型 / Embedding 费用与 Key | 承担并提供 | 接入与主备配置 |
| 内容安全 API | 提供 Key | 对接 |
| App 登录与用户 ID | 定义并实现发码/验签侧 | 换票与鉴权 |
| 知识内容与更新 | 负责 | 提供工具链 |
| 法务文案 | 提供 | 挂载 |
| 引擎与 BFF 缺陷（范围内） | — | 质保修复 |
| 模型幻觉业务损失 | 合同免责 + 人工复核约定 | 提供引用与拒答，不承诺零幻觉 |

## 2. 账号模型

```
管理域（自研后台账号）     用户域（使用方 App）
admin / operator / viewer   uid + 一次性 code → Session
仅运营后台                   仅 H5 / 对话 API
```

- App Token **不能**登录运营后台。  
- 后台账号 **不能**默认冒充 App 用户（调试开关仅内网）。  
- 若后台也要使用方 SSO：变更项（+3～5 人日量级）。

---

## 3. 一次性授权码（推荐主方案）

### 3.1 为何采用

链接泄露、浏览器历史、分享转发会导致长期 Token 被盗用。一次性 code 降低该风险，是 WebView 嵌入的常见做法。

### 3.2 时序

1. 用户在 App 内已登录。  
2. App **服务端**（或受保护接口）向 BFF 申请 code：`POST /api/v1/auth/app-code`（需 App 服务端凭证）。  
3. BFF 返回 `code`（TTL ≤ 5 分钟，单次）。  
4. App 打开：`https://{h5}/chat?code=...&channel=app`。  
5. H5：`POST /api/v1/auth/exchange` → 设置 **HttpOnly Secure Cookie（Session）**，code 作废。  
6. 后续对话只带 Cookie / Session，不再把身份放在 URL。

### 3.3 使用方必做

| # | 任务 | 交付物 |
|---|------|--------|
| 1 | 实现服务端申请 code（不可把 App 服务端密钥下发到前端） | 接口说明 |
| 2 | WebView 打开约定 URL | 测试包 |
| 3 | 提供用户字段映射：`sub`（用户 ID）、可选会员等级 | 字段表 |
| 4 | （可选）JSBridge：`close`；Phase 2 再要 `openGoods` / `share` / `saveImage` | 方法名文档 |

### 3.4 JWT 备选

仅用于联调或使用方无法做 code 时：短时 JWT（≤60 分钟）走 Header。生产仍建议尽快切 code。

## 4. 浏览器访问（使用方勾选）

| 选项 | 行为 | 默认 |
|------|------|------|
| A 禁止浏览器 | 无有效 Session/签名则引导 App | 敏感内部库 |
| **B 受限浏览器** | 游客极低额度或强制登录 | **推荐默认** |
| C 完全开放 Web | 独立完整 Web 产品 | 工期大，另评 |

---

## 5. API 概要（BFF 对外）

### 5.1 对话 SSE

`POST /api/v1/chat/completions`（需登录 Session）

事件示例：`meta` / `delta` / `citation` / `done` / `error`

### 5.2 额度

`GET /api/v1/me/quota` → 剩余次数、套餐

### 5.3 错误码

| code | 前端 |
|------|------|
| `UNAUTHORIZED` | 回 App 重开 |
| `QUOTA_EXCEEDED` | 额度提示 |
| `CONTENT_BLOCKED` | 违规提示 |
| `UPSTREAM_ERROR` | 可重试 |

完整 OpenAPI 在联调前交付。

## 7. 验收（Phase 1）

1. 运营可完成语料入库且状态就绪。  
2. 共同题集 Top3 召回命中率 ≥80%。  
3. App 内 code 免登，流式问答含引用。  
4. 无依据时拒答（抽测）。  
5. 额度用尽返回约定错误。  
6. 审计可查（脱敏）。  
7. 按手册完成一次干净部署；**C 端看不到 RAGFlow 原生控制台**。

工期自「环境 + Key + 发码联调账号就绪」起算；使用方阻塞不计入平台方延误。
