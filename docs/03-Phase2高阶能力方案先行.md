# Phase 2+ 高阶能力（方案先行）

| 项 | 内容 |
|---|---|
| 版本 | v2.0 |
| 状态 | **只出方案，不进半个月交付** |
| 前提 | Phase 1：RAGFlow 引擎 + Go BFF + assistant-ui 已稳定 |

---

## 1. 商品推荐

- 商品主数据结构化存储 + 语义字段向量化（可进 RAGFlow 或独立表）。  
- BFF 做属性过滤与精排；LLM 只写推荐理由。  
- H5 用 assistant-ui **自定义消息**渲染 `goods_card`。  
- 使用方提供：商品 API / 同步表、`goods_id`、详情 deep link、JSBridge `openGoods`。

---

## 2. 营销海报

1. **先做本地模板渲染**（可控、低成本）。  
2. 再按需接国内生图 API；价格等字段本地叠字，避免模型改价。  
3. 额度按 `capability=image` 计量（BFF 已有分能力额度表即可扩展）。

---

## 3. 短视频

- 异步任务 + 国内视频 API；BFF 只调度。  
- 禁止同步堵死对话连接。  
- 生成后内容安全审核。

---

## 4. Agent 编排增强（可选）

| 选项 | 用途 |
|------|------|
| **Mastra（Apache 核心）** | TS 侧工具工作流（若团队偏 TS） |
| **Eino** | Go 侧 Tool/多步 Agent（与现有 BFF 同语言） |
| 继续薄 BFF | 工具少时不必上框架 |

检索仍建议走 **RAGFlow**，避免用 Agent 框架重做文档引擎。

---

## 5. 模型网关

仅当渠道与计费运营复杂度显著上升时，再评估**可无 UI / 可嵌入**的网关；仍不默认交付 NewAPI 控制台给使用方终端用户。
